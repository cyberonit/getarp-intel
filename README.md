getarp v2 is built from scratch rather than migrated. A sensor runs the decoys and the IDS and is treated as hostile. A core (8 vCPU, 32 GB) holds the data, the credentials and the dashboard. Every service runs natively as a package or a systemd unit, configured by Ansible on VMs created by Terraform, so the whole system can be rebuilt from the repository.
The zero-trust controls from the previous review are part of the design here, not fixes on top: keys instead of addresses, admin access only through the tunnel, no public admin surface, keys created where they are used, and logs and backups in an account the core cannot delete.
The core starts with an empty database created from the repository's schema. Whether and how to bring in the old VM's history is decided once v2 is running (section 13). That keeps the build independent of the old system and lets v2 go live without waiting for a data move.
